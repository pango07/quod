# Separately gated matrix components

The [v2 ledger gate](https://github.com/pango07/quod/actions/runs/42407351138) passed 152 checks and an independent data-only audit with zero issues. All 108 receipts preserve the actual 3,947 native-conformed test states, including duplicate test names and the all-skipped file. Failures, unknown diagnostics, incomplete completion, pending asynchronous work, forged current identities and missing external byte authority are rejected. Receipt data totals 12,822,280 bytes; the conservative base64 collection bound is 17,152,308 bytes, below the 32 MiB pack limit. No cache was published, and this gate claims no actual SDK authentication.

The first ledger gate failed before minting any receipt because the exact compact native JSON reporter format was missing from the accepted formats. The correction accepts that producer's exact `JSON.stringify` output and adds duplicate-key negatives for both native producers.

The [paired source-AST gate](https://github.com/pango07/quod/actions/runs/42406920412) passed all 85 paired/invalidation checks, all 55 compiler controls and the full 120-instance native comparison. Independent archive and data audits pass with zero issues. All 12 alternating cached/uncached pairs have identical complete bundle bytes and compile identities. The cached parses total 6.859s versus 8.354s without caching, an observed 17.9% reduction in this one same-runner diagnostic; every pair is faster. The cache reports 456 actual cross-build syntax-tree hits while retaining at most 128 entries and 8 MiB of source bytes. All source reads, resolutions, glob discovery and final bundle parsing still run freshly.

This is a compiler component result, not a full-job speedup. The full correctness probe still retains 108 managed instances, 12 ordinary instances and all 4,131 native states with zero disagreements. The original twelve-commit cost target and genuine floor+8s full-job hit remain open.

The [machine-readable evidence](managed-vitest-matrix-components.json) includes full source pins, archive sizes/digests and independent audit outputs. Standalone readers are [matrix-ledger-audit.py](../../scripts/bench-vitest/managed/matrix-ledger-audit.py), [source-tree-cache-audit.py](../../scripts/bench-vitest/managed/source-tree-cache-audit.py) and [matrix-audit.py](../../scripts/bench-vitest/managed/matrix-audit.py). They inspect artifact bytes as data and execute no downloaded code.
