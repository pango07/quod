## Reading the hit rate

Every one of the 40 commits changes a recorded input, so 0 hits is the
right answer under the current schema, and Stillpass costs the observed
run on every commit (605s against 431s plain; the per-commit gap, ~4.3s,
is larger than the overhead bench's because the history also pays each
new venv's snapshot build and a lookup that deserializes every earlier
25k-entry manifest of the key before missing).

What changed, by commit: source and tests (27), a docs page or AGENTS.md
only (6: `470f986`, `04741d0`, `d4df01a`, `414af4f`, `2ec33ec`,
`fe000fb`), dependency bumps that change only uv.lock and so the venv (4), and releases
that bump `starlette/__init__.py` (3). The six docs-only commits miss only
because pytest's collection resolves every file it walks and a lookup
records the file's content; with existence-only records for files that
are only looked up (the next step in `polyglot-corpus.md`) they would hit.
